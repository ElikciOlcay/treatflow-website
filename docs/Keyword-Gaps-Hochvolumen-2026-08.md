# Keyword-Gaps mit hohem Suchvolumen (DE)

**Stand:** 07.08.2026  
**Markt:** Deutschland  
**Quellen:** Performance Suite Keyword-DB (OSG, Stand Juni 2026), Google Suggest (DE), Abgleich mit treatflow.io Sitemap/Pages  
**Hinweis:** Google Ads Keyword Planner / Searchvolume.io waren automatisiert nicht nutzbar (Login bzw. reCAPTCHA). Volumen = monatliche Suchanfragen laut Performance Suite.

## Methode

1. Seed-Keywords aus Treatflow-Portfolio + Wettbewerber + angrenzende Branchen
2. Google Suggest DE für Demand-Signale (202 Unique Suggestions)
3. Suchvolumen aus Performance Suite Keyword-DB
4. Gap = hohes SV **und** keine dedizierte Landingpage / kein starkes Targeting auf treatflow.io
